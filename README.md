# ProxiJournal

ProxiJournal is a private offline mobile journaling application built using React Native and Expo. It allows users to create and manage journal entries locally on their mobile device.

The application supports text-based journal entries, tags, audio recordings, images and file attachments.

## Features

* Create journal entries
* Edit existing entries
* Delete journal entries
* Add tags to journal entries
* Record audio
* Play recorded audio
* Attach images
* Attach files
* Search/explore saved journal entries
* Local offline storage
* SQLite database
* Journal statistics
* Settings and data management

## Database Structure

The application uses SQLite for local offline storage.

### Notes Table

| Column    | Type    | Description            |
| --------- | ------- | ---------------------- |
| id        | INTEGER | Primary key            |
| title     | TEXT    | Journal title          |
| body      | TEXT    | Journal content        |
| timestamp | TEXT    | Creation time          |
| tags      | TEXT    | User-defined tags      |
| synced    | INTEGER | Synchronization status |

### Attachments Table

| Column     | Type    | Description              |
| ---------- | ------- | ------------------------ |
| id         | INTEGER | Primary key              |
| note_id    | INTEGER | Related journal entry    |
| type       | TEXT    | Image, audio or file     |
| file_name  | TEXT    | Attachment name          |
| file_uri   | TEXT    | Local file location      |
| created_at | TEXT    | Attachment creation time |

Each journal entry can have multiple attachments.

## Application Flow

Home Screen
→ Create Journal Entry
→ Enter title/content/tags
→ Add attachments
→ Save
→ Note Detail

Users can also edit or delete existing journal entries.

## Setup Instructions

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd ProxiJournal
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the application

```bash
npx expo start
```

For tunnel mode:

```bash
npx expo start --tunnel
```

### 5. Run on Android/iOS

Install Expo Go on the mobile device and scan the QR code generated by Expo.

For Android emulator:

```bash
npx expo start --android
```

For iOS simulator on macOS:

```bash
npx expo start --ios
```

## APIs / Native Modules Used

The application primarily works offline and does not require a backend REST API.

The following Expo modules provide device functionality:

* Expo SQLite — local database
* Expo Audio — microphone recording and audio playback
* Expo Image Picker — image selection
* Expo Document Picker — file selection
* Expo Router — navigation

## Key Implementation Challenges

### 1. Offline Data Storage

The application needed to store journal entries without requiring an internet connection. SQLite was used to provide persistent local storage.

### 2. File Attachments

Images, audio recordings and files have different formats and storage locations. The application stores their local URI and metadata in the attachments table.

### 3. Audio Recording and Playback

Audio recording required microphone permissions and integration with Expo Audio. Audio playback was implemented separately on the note detail screen.

### 4. Navigation

Expo Router was used to navigate between Home, Create, Explore, Settings and dynamic Note Detail screens.

### 5. Keeping Screens Updated

Database data is reloaded when screens receive focus so that newly created, edited or deleted entries are reflected immediately.
